## 前言

这是我的个人博客搭建记录。

建立这个博客的初衷，是希望有一个长期保存技术学习、个人创作、独立游戏开发记录和生活随笔的地方。

相比于零散地记录在不同平台，我更希望通过自己的博客，逐步建立一套能够长期维护的个人知识库。

## 技术选型

目前博客采用以下技术：

| 项目 | 选择 |
|---|---|
| 静态博客框架 | Hexo |
| 博客主题 | Butterfly |
| 运行环境 | Node.js |
| 版本管理 | Git |
| 部署平台 | GitHub Pages |
| 本地开发环境 | Windows |

## 博客内容规划

目前计划将博客内容分为以下几个方向：

- 技术学习：编程、软件开发、工具使用和技术实践。
- 游戏开发：游戏设计、开发日志、技术实现和项目进度。
- 个人创作：世界观构建、创意设计和原创作品。
- 生活随笔：日常记录、个人思考和灵感。
- 知识库：整理长期有价值的知识、教程和资料。

## 后续计划

接下来将继续完善博客页面、导航结构和视觉样式，并逐步配置 GitHub Pages 部署。

希望这里能够成为一个持续记录、持续创作的个人空间。
